# E-Market Web App

PHP e-commerce web application.

## Features

- Product catalogue
- Configurable routing via .htaccess
- Composer-managed dependencies

## Tech Stack

- PHP

## Getting Started

```bash
git clone https://github.com/ghostland-dev/emarket-php.git
cd emarket-php
composer install
php -S localhost:8000
```
